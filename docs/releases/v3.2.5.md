# k8s-do v3.2.5

## 반영 내용

이 버전은 현장 테스트 중 확인된 개선 사항을 반영한 버전입니다.

### 1. 명령 체계 개선

기존 호환 방식은 유지합니다.

```bash
k8s-do <cluster> <node>
```

명확한 SSH 접속 명령도 추가했습니다.

```bash
k8s-do ssh <cluster> <node>
```

예시:

```bash
k8s-do ssh tkg-example-prd-workload-cluster-001 tkg-example-prd-workload-cluster-001-md-0-a1b2c-d3e4f-xn6xb
```

### 2. Bash completion 안정화

Tab 자동완성은 더 이상 노드 테이블을 출력하지 않습니다.

자동완성은 다음 내부 명령만 사용합니다.

```bash
k8s-do __complete node-values <cluster>
```

이 명령은 kubectl/SSH를 새로 호출하지 않고, 기존 노드 cache만 읽습니다.
따라서 Tab 입력 중 사번/SSO/인증 프롬프트가 뜨는 문제를 방지합니다.

노드 cache는 기본적으로 아래에 저장됩니다.

```bash
${XDG_CACHE_HOME:-$HOME/.cache}/k8s-do/nodes
```

root 사용 시 예시:

```bash
/root/.cache/k8s-do/nodes
```

노드 cache 생성/갱신:

```bash
k8s-do nodes <cluster>
```

### 3. doctor 출력 경로 개선

`--output`을 생략하면 현재 디렉터리에 파일을 만들지 않고 아래 디렉터리에 저장합니다.

```bash
/tmp/k8s-do-doctor
```

예시:

```bash
k8s-do doctor <cluster> <node>
```

직접 지정도 가능합니다.

```bash
k8s-do doctor <cluster> <node> --output /tmp/k8s-do-doctor/node01.log
```

doctor는 상단에 Quick Diagnosis Summary를 추가하여 Node Ready 상태, Scheduling 상태, 문제 Pod 수, Node Warning Event 수를 먼저 보여줍니다.

### 4. egress-check 출력 개선

기본 출력은 요약 중심으로 변경했습니다.

기본 실행:

```bash
k8s-do egress-check <cluster> <egress-node> \
  --egress-ip <egress-ip> \
  --dst <destination-ip> \
  --port <port>
```

기본 출력은 다음 중심입니다.

- Pod connectivity
- owner interface
- route interface
- capture interface
- ARP DAD duplicate check result
- SNAT 관측 여부
- return traffic 관측 여부
- 최종 PASS/WARN/FAIL 판정

전체 tcpdump/conntrack 원문은 기본적으로 파일에만 저장됩니다.

기본 저장 위치:

```bash
/tmp/k8s-do-egress
```

전체 원문을 터미널에도 보고 싶으면 `--verbose`를 사용합니다.

```bash
k8s-do egress-check <cluster> <egress-node> \
  --egress-ip <egress-ip> \
  --dst <destination-ip> \
  --port <port> \
  --verbose
```

### 5. ARP 중복 IP 검사 유지

ARP 검사는 일반 arping이 아니라 DAD 방식으로 수행합니다.

```bash
arping -D -I <route-interface> -c 5 -w 5 <egress-ip>
```

결과 해석:

- 응답 MAC 0개: 중복 ARP 응답 증거 없음
- 응답 MAC 1개 이상: 동일 Egress IP에 대한 응답이 있으므로 중복 소유 또는 proxy-ARP 가능성 경고

ARP는 overlay/proxy-ARP 환경에서 부재 증명은 아니므로 보조 증거로만 사용합니다.

## 설치

```bash
tar -xzf k8s-do-v3.2.5-bundle.tar.gz
cd k8s-do-v3.2.5-bundle
./install-k8s-do.sh
complete -r k8s-do 2>/dev/null
source /etc/bash_completion.d/k8s-do
hash -r
```

## 확인

```bash
k8s-do version
k8s-do list
k8s-do nodes <cluster>
k8s-do __complete node-values <cluster>
```

`k8s-do __complete node-values <cluster>`는 노드명만 출력되어야 합니다.
`INDEX`, `NODE`, `INTERNAL-IP`, `Ready`, `Enabled`가 출력되면 completion 파일이 이전 버전입니다.
