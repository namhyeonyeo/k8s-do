# k8s-do v3.2.4

This release fixes Tab completion side effects.

## Changes

- Keeps `/srv/k8s/file/ssh/kubeconfigs` and `/srv/k8s/file/ssh/privatekey` defaults.
- Strips `-kubeconfig` from kubeconfig filenames.
- Supports private key filenames ending with `-ssh-privatekey`.
- Stops printing node tables during Tab completion.
- Stops Tab completion from triggering kubectl/SSH/auth prompts.
- Node completion uses the existing node cache only. Run `k8s-do nodes <cluster>` to refresh cache.

## Install

```bash
tar -xzf k8s-do-v3.2.4-bundle.tar.gz
cd k8s-do-v3.2.4-bundle
./install-k8s-do.sh
complete -r k8s-do 2>/dev/null
source /etc/bash_completion.d/k8s-do
hash -r
```

## Verify

```bash
k8s-do version
k8s-do list
k8s-do nodes <cluster>
k8s-do __complete node-values <cluster>
```

`k8s-do __complete node-values <cluster>` should print only node names. It should not show a table and should not ask for employee number.
