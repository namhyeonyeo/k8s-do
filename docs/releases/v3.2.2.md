# k8s-do v3.2.2

## 반영된 수정사항

이번 버전은 오늘 운영 테스트 중 확인된 이슈를 모두 반영한 버전이다.

### 1. 기본 경로 변경

기본 static 경로를 `/srv/tanzu` 계열에서 `/srv/k8s` 계열로 변경했다.

```bash
STATIC_KUBECONFIG_DIR="/srv/k8s/file/ssh/kubeconfigs"
STATIC_PRIVATE_KEY_DIR="/srv/k8s/file/ssh/privatekey"
```

### 2. kubeconfig 파일명 suffix 처리

다음 형태의 kubeconfig 파일명을 자동으로 클러스터명으로 변환한다.

```text
tkg-example-prd-workload-cluster-001-kubeconfig
→ tkg-example-prd-workload-cluster-001
```

지원 예시는 다음과 같다.

```text
dev-workload.conf                         -> dev-workload
prod-workload.kubeconfig                  -> prod-workload
stage-workload.yaml                       -> stage-workload
tkg-xxx-workload-cluster-001-kubeconfig   -> tkg-xxx-workload-cluster-001
```

### 3. private key 파일명 suffix 처리

다음 형태의 private key 파일명을 자동으로 인식한다.

```text
<cluster-name>
<cluster-name>.pem
<cluster-name>.key
<cluster-name>-ssh-privatekey
<cluster-name>-ssh-privatekey.pem
<cluster-name>-ssh-privatekey.key
<cluster-name>-ssh
<cluster-name>-ssh.pem
<cluster-name>-ssh.key
```

운영에서 확인된 아래 파일명을 그대로 사용할 수 있다.

```text
tkg-example-prd-workload-cluster-001-ssh-privatekey
```

### 4. Bash Tab completion 출력 분리

`k8s-do nodes <cluster>`는 사람이 보는 표를 출력한다.

```bash
k8s-do nodes tkg-example-prd-workload-cluster-001
```

`k8s-do __complete nodes <cluster>`는 Bash completion 전용이므로 노드명만 한 줄씩 출력한다.

```bash
k8s-do __complete nodes tkg-example-prd-workload-cluster-001
```

정상 예시:

```text
tkg-example-prd-workload-cluster-001-md-0-a1b2c-d3e4f-k6ncv
tkg-example-prd-workload-cluster-001-md-0-a1b2c-d3e4f-psqfs
```

아래 값이 나오면 비정상이다.

```text
INDEX
NODE
INTERNAL-IP
Ready
Enabled
```

### 5. Human-readable node table helper 추가

completion wrapper가 화면에 노드명/IP를 보기 좋게 보여줄 수 있도록 별도 helper를 추가했다.

```bash
k8s-do __complete node-table <cluster>
```

이 명령은 아래처럼 출력한다.

```text
INDEX NODE                                                   INTERNAL-IP      STATUS     SCHEDULING   VERSION
----- ----                                                   -----------      ------     ----------   -------
1     tkg-example-prd-workload-cluster-001-md-...-k6ncv          10.50.93.46      Ready      Enabled      v1.33.1+vmware.1-fips
```

## 설치

```bash
tar -xzf k8s-do-v3.2.2-bundle.tar.gz
cd k8s-do-v3.2.2-bundle
./install-k8s-do.sh
source /etc/bash_completion.d/k8s-do
```

수동 설치가 필요하면 아래처럼 한다.

```bash
install -d -m 750 /etc/k8s-do
install -m 755 k8s-do /usr/local/bin/k8s-do
install -m 644 k8s-do.completion /etc/bash_completion.d/k8s-do
install -m 640 config.sh /etc/k8s-do/config.sh
source /etc/bash_completion.d/k8s-do
```

## 운영 확인 명령

```bash
k8s-do version
k8s-do __complete clusters
k8s-do list
k8s-do nodes <cluster>
k8s-do __complete nodes <cluster>
k8s-do __complete node-table <cluster>
```

## cache 초기화

기존 completion 결과가 남아 있으면 cache를 초기화한다.

```bash
k8s-do refresh
complete -r k8s-do 2>/dev/null
source /etc/bash_completion.d/k8s-do
hash -r
```
