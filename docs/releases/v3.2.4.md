# k8s-do v3.2.4

## 변경 사항

### egress-check Duplicate IP Probe 보완

v3.2.4에서는 `egress-check`의 ARP 중복 검사 방식을 일반 `arping`에서 Duplicate Address Detection 방식으로 변경했다.

기존:

```bash
arping -I <interface> <egress-ip>
```

변경:

```bash
arping -D -I <arp-interface> -c 5 -w 5 <egress-ip>
```

## 인터페이스 역할 분리

`egress-check` 결과에서 인터페이스 의미를 분리해서 출력한다.

- `owner_interface`: Egress IP가 실제 노드에 할당된 인터페이스. Antrea Egress 환경에서는 보통 `antrea-egress0`.
- `route_interface`: 목적지로 라우팅할 때 커널이 선택한 실제 인터페이스. 보통 `eth0` 또는 `ens*`.
- `capture_interface`: tcpdump external capture에 사용할 인터페이스. 기본은 `route_interface`, `--iface` 지정 시 override.
- `arp_interface`: Egress IP 중복 검사에 사용할 실제 L2 인터페이스. 기본은 `route_interface`, `--iface` 지정 시 override.

## ARP 결과 판정

- `arp_unique_response_macs=0`: 중복 ARP 응답 증거 없음. 단, overlay/proxy-ARP 환경에서는 부재 증명은 아님.
- `arp_unique_response_macs>=1`: Egress IP에 대해 응답 MAC이 관측됨. 중복 소유 또는 proxy-ARP 응답 가능성이 있어 return code 3.

## 사용 예시

```bash
k8s-do egress-check tkg-example-prd-workload-cluster-001 \
  tkg-example-prd-workload-cluster-001-md-0-a1b2c-d3e4f-xn6xb \
  --egress-ip 10.50.93.251 \
  --dst 10.50.91.49 \
  --port 8522
```

명시적으로 ARP/tcpdump 인터페이스를 지정하려면:

```bash
k8s-do egress-check tkg-example-prd-workload-cluster-001 \
  tkg-example-prd-workload-cluster-001-md-0-a1b2c-d3e4f-xn6xb \
  --egress-ip 10.50.93.251 \
  --dst 10.50.91.49 \
  --port 8522 \
  --iface eth0
```
